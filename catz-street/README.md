# Grand Theft Catz – Street Hustler (3D)

Third-person 3D version using Three.js (vendored in `js/vendor`). The Catz panthers are billboard sprites rendered from the Catz Fight rig.
No build step: serve the folder and open `index.html`.

- Third-person on-foot and driving cameras, mouse/touch look
- Fists, kicks and a pistol; cops shoot back at 3+ stars
- Enter shops and the safehouse (bodega, pawn shop, fresh fits, record spot, home)
- Talk to strangers (rumours, favors, muggings), phone calls from OG Whiskers start missions
- 6-mission campaign, courier jobs, day/night, 90s radio

Sim code (`ents.js`, `missions.js`, `world.js`) is shared with the top-down prototype in `../catz-city`.
