# Grand Theft Catz – Street Hustler (prototype)

Standalone top-down GTA-style game starring the Catz panthers (rigged paper-doll sprites reused from Catz Fight).
No build step: serve the folder and open `index.html` (`python3 -m http.server`).

- Drive, drift, fight, carjack; wanted level with police; day/night; 90s boom-bap / g-funk radio (synthesised)
- 6-mission campaign from OG Whiskers, then endless courier jobs
- Keyboard (WASD, Shift, J/K/L, E, Space, R, Tab, P) and touch controls

Files: `js/world.js` (city), `js/ents.js` (cars/peds/AI), `js/missions.js`, `js/game.js` (loop/HUD), `js/audio.js`; `js/rig.js`, `js/poses.js`, `js/chars/*`, `assets/chars/*` come from the Catz repo.
